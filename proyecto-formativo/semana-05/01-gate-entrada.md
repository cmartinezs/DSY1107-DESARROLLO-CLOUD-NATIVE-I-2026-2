# 01 · Gate de entrada al flujo Full Stack seguro

Antes de modificar RegistrApp, demostrar fuera del proyecto:

- login;
- Access Token destinado a la API;
- diferencia ID Token / Access Token;
- issuer y audience;
- Gateway capaz de aceptar/rechazar;
- backend protegido.

Si uno de estos puntos falla, se corrige el lab antes de transferir.
