# 03 · Checkpoint de salida

## Debe existir

- propósito del proyecto;
- actores;
- recurso principal;
- tabla de endpoints;
- diagrama cliente → API;
- DevLog de la semana.

## No debe aparecer todavía como requisito

- IDaaS;
- JWT;
- RabbitMQ;
- Kafka;
- infraestructura añadida sin una competencia aprendida.

El estado versionado resultante es la entrada de Semana 2.
