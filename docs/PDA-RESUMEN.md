## Descripción

La asignatura desarrolla capacidades Cloud Native aplicadas a sistemas distribuidos. La ruta institucional progresa desde gestión y seguridad de APIs, continúa con mensajería asíncrona mediante colas y culmina con streaming de datos.

La implementación utiliza servicios y tecnologías como API Manager / API Gateway, Identity as a Service, Spring Boot, RabbitMQ y Kafka según la etapa formativa.

## Resultados de aprendizaje

- **RA1:** diseñar soluciones colaborativas usando API Manager e Identity as a Service para gestionar, escalar, filtrar, autenticar y securitizar APIs.
- **RA2:** desarrollar soluciones con colas y mensajería asíncrona cuando la carga o naturaleza del trabajo no conviene resolverla de forma síncrona.
- **RA3:** desarrollar soluciones con streaming de datos para problemas de performance y movimiento de información a gran escala.

→ Detalle en [Resultados de aprendizaje](./RESULTADOS-DE-APRENDIZAJE.md).
