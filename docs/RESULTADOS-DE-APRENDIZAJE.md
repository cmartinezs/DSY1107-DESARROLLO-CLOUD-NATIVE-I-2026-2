# Resultados de aprendizaje e indicadores · DSY1107

Fuente base: **PA - DSY1107 DESARROLLO CLOUD NATIVE I**.

## RA1 · API Manager + Identity as a Service

> Diseña soluciones de manera colaborativa, utilizando una plataforma API Manager y soluciones Identity as a Service, con el fin de gestionar, escalar, filtrar, autenticar y securitizar el uso de APIs.

- **IL1.1:** Configura API Manager para su uso en un sistema FullStack.
- **IL1.2:** Configura un servicio Identity as a Service para su uso en un sistema FullStack.
- **IL1.3:** Integra API Manager e Identity as a Service en un aplicativo FullStack desplegado en la nube.

## RA2 · Mensajería asíncrona

> Desarrolla soluciones utilizando colas para trabajar con mensajes asincrónicos, para dar respuesta a problemas en que la carga de trabajo es muy grande para usar el método de trabajo sincrónico.

- **IL2.1:** Configura un componente que utilice tecnología de cola para trabajar con mensajes asíncronos.
- **IL2.2:** Implementa una solución usando mensajes asíncronos para responder a los problemas planteados.
- **IL2.3:** Administra las colas para dar solución a distintos casos de uso.

## RA3 · Streaming de datos

> Desarrolla soluciones creativas, implementando stream de datos, para satisfacer los problemas que las colas asincrónicas no pueden solucionar en cuanto a performance y rendimiento de movimiento de información a gran escala.

- **IL3.1:** Configura una plataforma de Stream como paso previo a la implementación para procesar gran cantidad de datos.
- **IL3.2:** Implementa componentes que hacen uso de mensajería Stream para resolver los problemas planteados.
- **IL3.3:** Administra una plataforma de mensajería Stream para distintos casos de uso.

## Uso en el repositorio

Cada semana debe enlazar los RA/IL que realmente trabaja. Los laboratorios y ejercicios deben indicar qué indicador practican cuando corresponda. Las evaluaciones consolidan la evidencia sumativa por experiencia.
