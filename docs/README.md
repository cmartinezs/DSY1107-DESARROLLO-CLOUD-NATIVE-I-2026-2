# Material de apoyo

Esta carpeta reúne contenidos complementarios y guías de consulta para la asignatura.

## Contenidos

- conceptos transversales necesarios para comprender los laboratorios;
- guías de herramientas;
- material de apoyo para Git, HTTP, APIs y cloud;
- referencias que puedan ser útiles durante más de una semana.

El material específico de cada semana se encuentra en [`../semanas/`](../semanas/).

## Criterio de uso

Los contenidos de esta carpeta complementan el material institucional disponible en AVA. Cuando un concepto sea requisito para varias actividades, se mantendrá aquí para evitar duplicarlo en cada semana.
