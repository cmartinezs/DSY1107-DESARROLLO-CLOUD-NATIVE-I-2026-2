## Corrección pedagógica

La formulación anterior mezclaba el contenido de clases con el desafío transversal y hacía que ejemplos, demostraciones y laboratorios reutilizaran el mismo dominio. Esa regla queda anulada.

La regla vigente es:

```text
VERTICAL DE CONTENIDO
concepto
→ explicación
→ ejemplo autocontenido
→ mini ejercicio/laboratorio independiente
→ comprensión

VERTICAL TRANSVERSAL
comprensión alcanzada
→ transferencia a RegistrApp
→ incremento
→ evidencia
→ checkpoint
```

> **Primero se aprende fuera de RegistrApp. Después se transfiere a RegistrApp.**
