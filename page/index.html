Tu ruta de trabajo

En curso
  1. 1 · Comprende el concepto. Cierra gestión de APIs y trabaja OAuth2/OIDC, actores, tokens, scopes y responsabilidades sin depender de una consola cloud.
  2. 2 · Obsérvalo localmente. Usa los laboratorios canónicos para hacer visible routing, CORS, identidad, tokens, 401/403 y flujo cliente → gateway → backend.
  3. 3 · Relaciónalo con ReservApp. Mapea usuarios, cliente, IdP, gateway, API y permisos sobre el mismo dominio formativo.
  4. 4 · Transfiérelo a cloud. Cuando corresponda el laboratorio real, compara qué cambió al usar un proveedor y qué conceptos permanecieron.
  5. + Opcional. Revisa ejemplos, repite pruebas o investiga un caso real de OAuth2/OIDC y documenta sus actores.

Al terminar deberías poder explicar: el flujo y las responsabilidades sin necesitar mencionar AWS o Azure; después, recién mapear cada concepto al servicio concreto.
