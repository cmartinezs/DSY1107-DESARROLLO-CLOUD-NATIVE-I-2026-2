Esta semana · Semana 4 · 31 agosto–5 septiembre

Identity as a Service → Full Stack seguro

Semana 4
  1. 1 · Cierra el bloque 1.2. Completa usuarios externos, seguridad en API Manager, JWT/Claims y decodificación de tokens desde el último checkpoint real de tu sección.
  2. 2 · Conecta el frontend con identidad. Comprende MSAL, Authorization Code + PKCE, public clients, scopes y la diferencia entre ID token y access token.
  3. 3 · Protege el backend. Usa Spring Security como OAuth2 Resource Server y razona sobre issuer, audience, expiración, scopes, 401 y 403.
  4. 4 · Integra la arquitectura. Ubica responsabilidades entre SPA, Identity Provider, API Manager/Gateway y backend bajo defensa en profundidad.
  5. 5 · Prepárate para Parcial 1. Revisa rúbrica, condiciones de entrega y la aclaración sobre el nombre “Pedidos360”.

Al terminar deberías poder explicar: por qué el backend valida por sí mismo el access token, qué controles pertenecen al gateway y cuáles al Resource Server, y cómo se interpreta un 401 frente a un 403.
