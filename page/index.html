Mensajería asíncrona y RabbitMQ

RA2 · IL2.1
  1. Problema antes que herramienta. Distingue cuándo una capacidad requiere respuesta inmediata y cuándo conviene desacoplarla.
  2. Modelo básico. Producer → Broker → Queue → Consumer.
  3. RabbitMQ local. Levanta el broker con Docker y observa 5672/15672.
  4. Hello World. Publica y consume un mensaje con Spring AMQP.
  5. Routing explícito. DirectExchange, bindings y routing keys.
  6. Arquitectura. REST Controller y Rabbit Listener pueden activar la misma capacidad sin duplicar negocio.
