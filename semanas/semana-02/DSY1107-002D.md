## Bloque 3 · actividad de investigación + discusión

### Actividad individual o en parejas · 15 minutos

Investigar **un servicio real** donde exista OAuth2/OIDC.

Ejemplos posibles, sin limitar la elección:

- iniciar sesión con Google/Microsoft/GitHub;
- una aplicación conectándose a Google Drive;
- una herramienta conectándose a GitHub;
- una aplicación que solicita acceso a calendario, fotos u otro recurso.

Identificar:

1. usuario/resource owner;
2. cliente;
3. Authorization Server / proveedor de identidad;
4. recurso/API protegida;
5. si el caso parece centrado en autenticación, autorización o ambos.

### Puesta en común

Tomar 2–3 casos y corregir colectivamente el mapa de actores.

Luego introducir progresivamente:

- Access Token;
- ID Token;
- scopes;
- claims como concepto;
- por qué ID Token y Access Token no son intercambiables.

**Checkpoint:** cada estudiante debe poder explicar un flujo real sin repetir solo definiciones.
