## Idea que debe permanecer

```text
OAuth2 / OIDC → protocolos y flujos
IdP           → sistema que autentica y entrega identidad confiable
IAM           → disciplina amplia de identidad y acceso
IDaaS         → capacidades de identidad operadas como servicio
CIAM          → identidad y acceso orientados a clientes/usuarios externos
```

No es necesario memorizar marcas comerciales. Primero debe entenderse la capacidad y la responsabilidad arquitectónica.
