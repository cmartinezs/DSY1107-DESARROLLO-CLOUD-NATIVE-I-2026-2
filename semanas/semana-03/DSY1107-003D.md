## Punto de partida conservador

La última evidencia inequívoca dejó el laboratorio de API Gateway en progreso; OAuth2/OIDC fue trabajado conceptualmente. Starter, PKCE completo, matriz 401/403 y configuración real de identidad no deben darse por realizados sin evidencia posterior.

Por ello 003D **no comienza directamente en JWT/cloud**.

## Ruta de recuperación del contenido

```text
gateway defendible
→ actores OAuth2/OIDC
→ Authorization Code + PKCE
→ access token vs ID token
→ 401/403
→ JWT y claims
→ seguridad gateway/API
→ usuarios externos / CIAM
→ cloud según tiempo real
```

Usar ejemplos mínimos independientes para cada concepto. No convertir esa secuencia en una construcción guiada de RegistrApp.

## Estrategia de clase

La recuperación no consiste en repetir una presentación completa. Cada concepto se valida con una pregunta, dibujo o demostración corta. Lo que el curso demuestra se da por recuperado; lo que no, recibe explicación y práctica inmediata.

## Gate antes de JWT

No avanzar a JWT aplicado mientras el grupo no pueda:

- ubicar usuario, cliente, Authorization Server/IdP y Resource Server;
- explicar el propósito de PKCE;
- distinguir access token de ID token;
- explicar un caso de 401 y uno de 403.
