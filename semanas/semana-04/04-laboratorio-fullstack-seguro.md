→ [Abrir laboratorio canónico: `labs/fullstack-seguro/`](../../labs/fullstack-seguro/README.md)

Este archivo se conserva únicamente como **punto de entrada curricular** desde `semanas/semana-04/`; no mantiene una segunda copia del laboratorio.

## Competencias cubiertas

- Authorization Code + PKCE;
- MSAL en frontend;
- ID token vs access token;
- API Manager / Gateway;
- Spring Security OAuth2 Resource Server;
- issuer, audience, expiración y scopes;
- matriz 401 / 403 / 2xx;
- arquitectura segura y defensa en profundidad.
