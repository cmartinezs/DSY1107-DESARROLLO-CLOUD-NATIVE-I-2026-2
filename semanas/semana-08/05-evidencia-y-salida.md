# Evidencia y criterio de salida · Semana 08

## Evidencia mínima

- RabbitMQ ejecutándose;
- queue visible;
- exchange visible;
- bindings visibles;
- producer funcionando;
- consumer funcionando;
- routing keys coherentes;
- al menos dos mensajes observados;
- explicación del recorrido;
- separación entre infraestructura y lógica.

## Preguntas de salida

1. ¿Qué problema resuelve la asincronía?
2. ¿Qué almacena una queue?
3. ¿Qué hace un exchange?
4. ¿Qué función cumple un binding?
5. ¿Qué diferencia hay entre routing key y nombre de queue?
6. ¿Qué ocurriría si el consumer se detiene temporalmente?
7. ¿Por qué un listener no debería contener toda la lógica de negocio?
