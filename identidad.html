Cómo usar esta guía

Avanza por checkpoints, no por pantallas

Si una etapa falla, no continúes con la siguiente. Primero identifica si el problema pertenece a cuenta/suscripción, tenant, permisos, App Registration, usuario externo, user flow, MSAL, token o API Gateway.

Modelo mental

Guest manual antes de self-service

flowchart LR
    M[Admin invita Guest] --> U[Comprender tenant + Guest + aceptación]
    U --> S[Usuario se auto-registra]
    S --> L[Lifecycle administrado por IDaaS]

El auto-registro automatiza la incorporación al lifecycle; no reemplaza el concepto de usuario externo.

    API-->>SPA: Respuesta

Diagnóstico

Primero identifica la frontera que falló

  1. No aparece Azure for Students: cuenta o suscripción.
  2. No aparece el tenant: contexto de directorio.
  3. No puedo registrar app: permisos/política.
  4. Owner entra y compañero no: Guest, aceptación, assignment o tenant.
  5. No aparece self-service: configuración o permisos.
  6. Login funciona pero API falla: token, issuer, audience o scope.
