# 03 · Deuda vs alcance

Clasifica cada propuesta como **necesaria para cerrar el flujo seguro** o **alcance adicional**:

- corregir audience;
- agregar otra entidad CRUD;
- demostrar 401;
- mejorar CSS;
- corregir CORS del frontend real;
- crear un microservicio adicional;
- demostrar Bearer token end-to-end.

Justifica cada decisión en una frase.
