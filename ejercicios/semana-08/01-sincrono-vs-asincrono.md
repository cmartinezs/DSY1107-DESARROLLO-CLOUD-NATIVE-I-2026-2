# Ejercicio 1 · ¿Síncrono o asíncrono?

Para cada caso decide si conviene resolverlo de forma síncrona, asíncrona o si faltan datos.

1. Validar una contraseña durante login.
2. Enviar correo de confirmación después de crear una reserva.
3. Calcular el total de una compra antes de pagar.
4. Generar un PDF pesado después de aceptar una solicitud.
5. Registrar auditoría de una operación exitosa.

Para cada decisión explica:

- qué necesita el usuario inmediatamente;
- qué pasa si el componente secundario está lento;
- qué riesgo introduce una cola;
- qué evidencia te haría cambiar de decisión.
