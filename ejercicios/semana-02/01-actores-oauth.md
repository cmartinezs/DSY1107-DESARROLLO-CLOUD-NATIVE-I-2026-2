# 01 · Identificar actores

Escenario: una SPA permite a un usuario consultar sus reservas desde una API protegida y utiliza un proveedor de identidad externo.

Identifica:
- Resource Owner;
- Client;
- Authorization Server / IdP;
- Resource Server.

Luego dibuja el flujo de alto nivel de Authorization Code + PKCE.

## Restricción

No uses nombres de productos comerciales en la primera respuesta.
