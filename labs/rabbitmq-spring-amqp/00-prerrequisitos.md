# Etapa 0 · Prerrequisitos y línea base

## Objetivo

Comprobar que el entorno puede ejecutar RabbitMQ y una aplicación Spring Boot antes de agregar mensajería.

## Verificaciones

- Docker Desktop operativo;
- Java 21 disponible;
- Maven Wrapper o Maven disponible;
- IDE configurado;
- puerto `5672` libre;
- puerto `15672` libre.

## Evidencia

Registrar versiones y confirmar que Docker puede ejecutar un contenedor de prueba.

## Checkpoint

No continuar si Docker no funciona o si los puertos necesarios están ocupados sin una decisión consciente.
