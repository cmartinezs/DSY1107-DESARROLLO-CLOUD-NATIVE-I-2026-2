Esta semana · Semana 4 · 31 agosto–5 septiembre

Identity as a Service → Full Stack seguro → transferencia a RegistrApp

Semana 4
  1. 1 · Configura identidad correctamente. Verifica Azure for Students, tenant/directorio y permisos antes de registrar aplicaciones.
  2. 2 · Trabaja usuarios externos. Comprende Guest/B2B manual y trata self-service como extensión posterior.
  3. 3 · Practica IDaaS con Firebase. Construye Email/Password completo y luego Google Sign-In para comparar modelos administrados.
  4. 4 · Conecta el frontend con identidad. Usa MSAL, Authorization Code + PKCE, scopes y distingue ID token de access token.
  5. 5 · Protege la API. Usa dos App Registrations, valida issuer, audience y scope en Gateway y backend, y razona sobre 401/403.
  6. 6 · Transfiere solo después del gate. Lleva el patrón a RegistrApp de forma incremental; self-service no bloquea la integración base.

Al terminar deberías poder explicar: qué pertenece al dominio Identity, qué valida el laboratorio Full Stack y qué cambios se transfirieron realmente al proyecto formativo.
